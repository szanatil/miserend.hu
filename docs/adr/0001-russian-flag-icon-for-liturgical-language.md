# Russian national flag used for Russian-language masses

When adding Russian (`ru`) as a liturgical language, we considered using a neutral symbol (e.g. a Cyrillic script icon or Byzantine cross) instead of the Russian tricolor, given the political sensitivity of the Russian flag in Eastern Europe. The product owner explicitly confirmed the Russian national tricolor as the intended icon, consistent with how all other liturgical languages are represented by their country's flag (e.g. `ua` → Ukrainian flag, `sk` → Slovak flag). A neutral symbol would have been an inconsistent exception in the existing flag-per-language-code convention.

## Considered Options

- **Russian tricolor flag** ✓ — consistent with the existing convention; product owner confirmed
- **Neutral / liturgical symbol** — would break the flag-per-language convention and require a separate rendering path
